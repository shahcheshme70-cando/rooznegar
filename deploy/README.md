# روزنگار (دستیار کندو) · نسخهٔ ۰.۹

روزنگار یک ربات تلگرام و بله برای تیم است، همراه با یک داشبورد وب. Claude شما هم به آن وصل می‌شود.

**هر روز با هر نفر، به ساعت خودش:**
- **صبح:** برنامهٔ روز را خودش می‌فرستد. برنامه شب قبل ساخته شده و تا صبح در داشبورد قابل اصلاح است.
- **اگر شروع نزده باشد:** یک یادآوری کوتاه می‌فرستد.
- **ظهر:** یک خبر خوب یا یک نکته. سؤالی پرسیده نمی‌شود.
- **عصر:** گزارش را می‌گیرد، با متن یا صوت.
  - کار تحویل‌شده ثبت می‌شود، با فایلش، و نفر بعدِ زنجیره خبردار می‌شود.
  - برای کار ناتمام فقط دو سؤال دکمه‌ای می‌پرسد: «چقدر پیش رفت؟» و «کی تمام می‌شود؟». عکس از کار نیمه‌تمام هیچ‌وقت خواسته نمی‌شود.

**خودران:** شما فقط می‌گویید چه کسی چه کند؛ بقیه با ربات است.
- **کار تازه:** در ساعت کاری همان لحظه به او خبر می‌دهد (با دکمهٔ «دیدم»). قبل از برنامهٔ صبح، در همان برنامه می‌آید. بعد از ساعت کاری، صبح فردا.
- **زنجیره:** وقتی کسی حلقه‌اش را تمام کند، نفر بعد همان لحظه خبر می‌گیرد، نه فردا صبح.
- **پیام و یادآوری:** «به نیما بگو…» همان لحظه می‌رود. «فردا ساعت ۱۰ یادش بنداز…» سر همان ساعت (به وقت خودش). جوابش به شما برمی‌گردد و اگر بی‌جواب بماند، ۲۴ ساعت بعد دوباره می‌پرسد.
- **گزارش جامانده:** ۹۰ دقیقه بعد از سؤال عصر، یک یادآوری کوتاه.
- **موعد گذشته:** موقع گزارش می‌پرسد «موعدش دیروز بود؛ کی تمام می‌شود؟». اگر موعد کاری دو بار عقب برود، به شما خبر می‌دهد.
- **توازن:** هر نفر «ارزش روزانه» دارد و هر کار «ارزش». خلاصهٔ شب ارزش تحویل‌شدهٔ امروز، کسانی که کار آماده ندارند و پربارها را نشان می‌دهد. Claude قبل از سپردن کار، بار آن نفر را می‌بیند.
- **سقف:** هر نفر روزی حداکثر ۵ پیام خودکار می‌گیرد؛ بیشترش در برنامهٔ صبح بعد جمع می‌شود.

**یادگیری:** ربات از رفتار هر نفر یاد می‌گیرد و خودش را تنظیم می‌کند.
- **خودش عوض می‌کند (و به شما می‌گوید، با دکمهٔ «برگردان»):**
  - اگر کسی همیشه دیرتر از ساعت سؤال گزارش می‌دهد، سؤال به ساعت واقعی‌اش می‌رود.
  - اگر کسی همیشه قبل از یادآوری شروع، کارش را شروع کرده، یادآوری‌اش خاموش می‌شود؛ اگر دوباره دیر شروع کرد، روشن می‌شود.
  - اگر کسی گفت پیام زیاد است، پیام ظهرش خاموش می‌شود.
  - «برگردان» یعنی تنظیم قبلی برمی‌گردد و ربات دیگر ساعت‌های آن نفر را خودش عوض نمی‌کند (در صفحهٔ «آدم‌ها» هم قابل تنظیم است).
- **فقط به شما می‌گوید (تصمیم با شماست):** کسی که حتی با یادآوری گزارش نمی‌دهد، کسی که به پیگیری‌ها جواب نمی‌دهد، کسی که موعدهایش مدام عقب می‌رود. هر نکته حداکثر هفته‌ای یک بار.
- **پیام بی‌جواب:** ۲۴ ساعت بعد دوباره پرسیده می‌شود؛ اگر ۴۸ ساعت بی‌جواب ماند، به کسی که پرسیده بود خبر می‌دهد.
- **نظر بچه‌ها:** هر کس پیامی با «نظر:» شروع کند، یا وسط گزارش دربارهٔ خود ربات حرفی بزند، همان لحظه به شما می‌رسد و در مرور هفته هم می‌آید.
- **مرور هفته (پنجشنبه شب):** ارزش تحویل‌شدهٔ هر نفر در برابر هدف، گزارش‌های جامانده، کم‌کارها و نظرها.
- Claude هم «الگوی» هر نفر را می‌بیند (ساعت واقعی گزارش، جواب به پیگیری‌ها، عقب رفتن موعدها) و کار را با آن می‌سپارد.

**ارسال برای همه:** در داشبورد، صفحهٔ «ارسال برای همه»: ویدیو، عکس یا هر فایلی (تا ۵۰ مگ) با یک متن، برای همهٔ وصل‌ها، یک خط یا چند نفر. ویدیو در تلگرام و بله همان‌جا پخش می‌شود. نتیجه (چند نفر گرفتند، به چه کسی نرسید) در تلگرام برای فرستنده می‌آید. از Claude هم می‌شود گفت «به همه بگو…» یا «این ویدیو را برای همه بفرست»: Claude یک نشانی یک‌بارمصرف (۳۰ دقیقه) از روزنگار می‌گیرد و فایل را مستقیم می‌فرستد. برای این کار دامنهٔ روزنگار باید در Claude در فهرست دامنه‌های مجاز باشد (Settings ← Capabilities؛ در حساب سازمانی، مدیر سازمان در Organization settings ← Capabilities).

**برای شما:**
- **ساعت ۲۰:۴۵، خلاصهٔ شب:** چه کسی گزارش داد، گره‌ها، حلقه‌هایی که به نفر بعد رسید، موعدهای لغزنده، عددها، ارزش امروز، کم‌کار و پربار، و برنامهٔ فردای همه در یک پیام.
- **گره‌های قرمز** همان لحظه به شما می‌رسند.
- **کارهای عددی** (مثل متر مربع سنندج) هر روز با هدف سنجیده می‌شوند. اگر دو روز پشت هم زیر هدف باشند، پیشنهاد «نیروی اضافه» برای تأیید شما می‌آید.

**قاعده‌های ثابت:**
- ربات خودش هیچ کاری را «تمام‌شده» نمی‌زند؛ فقط چیزی را که نیرو بگوید ثبت می‌کند.
- اگر خواستید برنامهٔ صبح بدون تأیید شما نرود، در تنظیمات `"unapproved_plan": "wait"` بگذارید.
- کارهای مالی فقط برای مدیر و مالی دیده می‌شود.

## پیش از نصب

| چه چیزی | از کجا |
|---|---|
| **سرور** | همان سرور بارگذار (اوبونتو). سرور باید **بیرون از ایران** باشد، چون API کلاد و تلگرام از ایران باز نیستند. |
| **زیردامنه** | مثلاً `rooznegar.ghese-agha.ir`. یک رکورد A روی آی‌پی سرور بگذارید. |
| **ربات تلگرام** | در تلگرام به `@BotFather` بروید، `/newbot` بزنید و توکن را نگه دارید. |
| **ربات بله** (اختیاری) | در بله به بات‌فادر بروید، ربات بسازید و توکن را نگه دارید. |
| **کلید API کلاد** | از platform.claude.com، روی سازمانی که ۲۰۰ دلار اعتبار ماهانهٔ Max به آن وصل است: Settings ← API keys. |
| **صوت** (اختیاری) | یک سرویس تبدیل گفتار با API سازگار با OpenAI. پایین‌تر توضیح داده شده. |

بدون کلید API هم ربات کار می‌کند، ولی فقط با دکمه‌ها و بدون فهمیدن متن آزاد.

## نصب

```bash
# بسته را روی سرور بیاورید و باز کنید
unzip rooznegar-0.1.zip && cd rooznegar
sudo ./install.sh rooznegar.ghese-agha.ir
```

نصب، سرویس systemd و nginx و SSL را آماده می‌کند، ولی **سرویس را روشن نمی‌کند**. بعد از آن:

```bash
sudo nano /etc/rooznegar/config.json        # توکن ربات‌ها و کلید API را بگذارید
sudo -u rooznegar rooznegar seed /etc/rooznegar/seed.json      # تیم و پروژه‌ها
sudo -u rooznegar rooznegar user boss admin "نام شما"         # کاربر داشبورد؛ رمز می‌پرسد
sudo -u rooznegar rooznegar check            # آزمودن تلگرام، بله و Claude
sudo systemctl start rooznegar
```

بعد `https://rooznegar.ghese-agha.ir` را باز کنید و وارد شوید.

> فرمان‌های `seed` و `user` فقط وقتی کار می‌کنند که سرویس خاموش باشد. برای کاربر تازه: `sudo systemctl stop rooznegar`، فرمان را بزنید، بعد `start`. کاربرها را از صفحهٔ «کاربران و Claude» هم می‌شود ساخت، بدون خاموش کردن سرویس.

## راه‌اندازی تیم

1. **آدم‌ها:** `seed.json` نه نفر را با ریتم پیشنهادی وارد کرده است: احمد ۴ پیام در روز، سامی فقط ساعت ۷ عصر و در بله، بقیه گزارش عصر. در صفحهٔ «آدم‌ها» برای هر نفر این‌ها را درست کنید:
   - **منطقهٔ زمانی:** مثلاً `Europe/Istanbul`. ساعت‌ها به وقت خود اوست.
   - **پیام‌رسان**
   - **ساعت‌ها**
   - **روزهای تعطیل**
   - **نقش و خط**
   - اسم «مدیر» را هم به اسم خودتان عوض کنید.
2. **اتصال هر نفر:** کنار هر نفر یک **کد شش‌رقمی** است. کد را برایش بفرستید. او ربات را در تلگرام یا بله باز می‌کند و کد را می‌فرستد. خودتان هم با کد «مدیر» وصل شوید تا خلاصه‌ها و تأییدها برایتان بیاید.
3. **کارها:** در «کارها و زنجیره» هر کار این‌ها را دارد:
   - یک **نفر** و یک **پروژه**
   - یک **زنجیره**: بازار، ارزش یا نقد
   - یک **نوع**:
     - **یک‌روزه:** عصر فقط می‌پرسد «تمام شد؟».
     - **چندروزه:** پیشرفت و موعد را می‌پرسد.
     - **عددی:** هر روز یک عدد، با هدف روزانه و کل کار.
   - **«بعد از این حلقه»:** زنجیره را می‌سازد. وقتی کار قبلی تمام شود، این کار «آماده» می‌شود و صاحبش خبر می‌گیرد. مثلاً لی‌اوت ایلیا ← تایپوی احمد ← بارگذاری نسیم.
   - **«نکته یا لینک فایل‌ها»:** در برنامهٔ صبح برایش می‌رود.
4. **برنامهٔ فردا:** هر شب ساعت ۲۰:۳۰، از کارهای آمادهٔ هر نفر حداکثر سه مورد (به ترتیب اولویت) انتخاب می‌شود. ساعت ۲۰:۴۵ فهرستش برایتان می‌آید و تا صبح در صفحهٔ «برنامهٔ فردا» قابل اصلاح است؛ سر ساعت صبح هر نفر خودش می‌رود.
5. **ارزش:** در صفحهٔ «آدم‌ها» ارزش روزانهٔ هر نفر و در هر کار «ارزش کار» (میلیون تومان) را بنویسید تا توازن و ارزش تحویل‌شده حساب شود.

## وصل کردن Claude

در صفحهٔ «کاربران و Claude» هر کاربر یک **نشانی کانکتور** دارد. در Claude بروید به Settings ← Connectors ← Add custom connector، نشانی را بگذارید و ذخیره کنید. از آن به بعد می‌شود در هر چتی گفت:

- «گره‌های امروز چیست؟» یا «این هفته احمد روی سالن ۸ چقدر جلو رفته؟»
- «به حسن بگو متن ۴۱ و ۴۲ تا پنجشنبه می‌رسد.» همان لحظه از ربات می‌رود. اگر بگویید «اول متنش را نشانم بده»، پیش‌نویس می‌سازد.
- «فردا ساعت ۱۰ به سامی یادآوری کن متراژ دیروز را بفرستد.»
- «بار تیم چطور است؟ کی کار آماده ندارد؟»
- «برای نسیم یک کار بگذار: بارگذاری تابلو ۳۷ تا ۴۰، بعد از تایپوی احمد.»
- «برنامهٔ فردای احمد را این دو کار بگذار.»

**سطح دسترسی‌ها**

| نقش | چه چیزی را می‌بیند | چه کارهایی می‌تواند |
|---|---|---|
| مدیر | همه‌چیز | کار، پیام و یادآوری به همه، تأییدها و برنامه‌ها |
| همکار ارشد | همه‌چیز، جز مالی | کار، پیام و یادآوری. تأیید نهایی با مدیر است |
| مسئول خط | فقط آدم‌ها و کارهای خط خودش | کار، پیام و یادآوری، فقط به خط خودش |
| مالی | فقط کارهای نقد و مالی | — |

نشانی کانکتور مثل رمز است. اگر لو رفت، «نشانی تازه» بزنید.

## کانال فایل‌ها

فایل‌هایی که بچه‌ها می‌فرستند بهتر است در یک کانال خصوصی تلگرام ذخیره شوند، نه روی سرور. این‌طوری محدودیت ۲۰ مگ هم نیست، چون ربات فایل را دانلود نمی‌کند و فقط کپی می‌کند.

1. یک **کانال خصوصی** در تلگرام بسازید، مثلاً «فایل‌های روزنگار».
2. ربات را به کانال اضافه کنید و **ادمین** کنید، با اجازهٔ ارسال و ویرایش پیام.
3. شناسهٔ عددی کانال را پیدا کنید: یک پیام از کانال را برای `@userinfobot` یا `@RawDataBot` فوروارد کنید. شناسه با `-100` شروع می‌شود.
4. در تنظیمات بگذارید: `"telegram_files_chat": -1001234567890`. برای بله هم همین کار را بکنید و `"bale_files_chat"` را پر کنید.

**از آن به بعد همه‌چیز در همین کانال تلگرام آرشیو می‌شود، حتی آنچه در بله می‌رسد:**
- **فایل‌های تلگرام** بدون دانلود کپی می‌شوند، پس محدودیت حجم ندارند.
- **فایل‌های بله** را ربات از بله می‌گیرد و در کانال تلگرام آپلود می‌کند. چیزی روی سرور نمی‌ماند. اسم فایل در آرشیو این‌طور می‌شود: `1405-08-13_علیرضا-حاجی-سامی_plan.pdf`
- **متن هر گزارش** هم با هشتگ در کانال می‌رود (`"archive_reports": true`).

**کپشن هر فایل یک شناسنامهٔ ثابت است:**
```
📎 plan.pdf
✔ نقشهٔ اجرایی سقف              ← وقتی معلوم شد مال کدام کار است
📁 #حرف_نو_سنندج · #زنجیره_ارزش
👤 #علیرضا_حاجی_سامی · #خط_ساخت
📅 چهارشنبه ۱۳ آبان ۱۴۰۵ · #آبان_۱۴۰۵
💬 توضیحی که خودش نوشته
```
تا معلوم نشده فایل مال کدام کار است، به‌جای خط ✔ نوشته می‌شود «⏳ کارش هنوز مشخص نشده». وقتی در گزارش معلوم شد، ربات کپشن را خودش کامل می‌کند.

**جستجو در کانال:** روی هر هشتگ بزنید، یا در جستجوی کانال بنویسید، مثلاً `#حرف_نو_سنندج`، `#احمد_طهماسبی`، `#آبان_۱۴۰۵` یا `#گزارش`. چند هشتگ را با هم هم می‌شود جستجو کرد. در داشبورد هم کنار هر کار لینک مستقیم به همان پیام کانال هست.

> محدودیت: ربات‌ها فایل بزرگ‌تر از ۲۰ مگ را از بله نمی‌توانند بگیرند و بزرگ‌تر از ۵۰ مگ را در تلگرام نمی‌توانند آپلود کنند. برای فایل‌های خیلی بزرگ از بارگذار استفاده کنید. فایل‌هایی که مستقیم در تلگرام فرستاده شوند این محدودیت را ندارند.

## بارگذار (فایل‌های بزرگ)

برای فایل‌هایی که از راه ربات نمی‌آیند، یعنی فایل‌های بلهٔ بزرگ‌تر از ۲۰ مگ یا هر چیزی بزرگ‌تر از ۵۰ مگ برای آرشیو، روزنگار از **لینک آپلود بارگذار** استفاده می‌کند. خود بارگذار تغییری لازم ندارد.

**روند از دید نیرو:**
1. می‌نویسد «لینک آپلود». اگر فایلش بزرگ بوده باشد، ربات خودش پیشنهاد می‌دهد.
2. ربات می‌پرسد «مال کدام کار است؟» و دکمهٔ کارهایش را نشان می‌دهد. اگر فقط یک کار داشته باشد، نمی‌پرسد.
3. ربات لینک آپلود بارگذار را برای پوشهٔ `تحویل/<اسم کار>` همان پروژه می‌سازد و می‌فرستد. لینک ۳ روز باز است، حجمش محدودیتی ندارد و اگر آپلود قطع شود از همان‌جا ادامه می‌دهد.
4. هر ۹۰ ثانیه وضعیت لینک بررسی می‌شود. وقتی فایل رسید:
   - به خودش می‌گوید «رسید ✔».
   - فایل با لینک ثابت بارگذار به همان کار در داشبورد وصل می‌شود.
   - در کانال تلگرام همان شناسنامهٔ کپشن می‌آید، به‌علاوهٔ `🔗` لینک فایل.

**راه‌اندازی:**
1. در بارگذار یک کاربر برای روزنگار بسازید:
   ```bash
   sudo bargozar user add rooznegar
   ```
2. در `config.json` بگذارید:
   ```json
   "bargozar_url": "https://files.ghese-agha.ir",
   "bargozar_user": "rooznegar",
   "bargozar_pass": "رمز همان کاربر"
   ```
3. در داشبورد روزنگار ← **پروژه‌ها**، برای هر پروژه «نام پروژه در بارگذار» را بنویسید، مثلاً `harfe-no`. همان نامی است که در نشانی‌های بارگذار می‌آید: `/f/harfe-no/...`
4. `sudo -u rooznegar rooznegar check` باید بنویسد `✓ بارگذار` و تعداد فایل‌های یک پروژه را نشان دهد.

> روزنگار با بارگذار همان‌طور حرف می‌زند که خود صفحهٔ پنل بارگذار حرف می‌زند. اگر بعداً نسخه‌ای از بارگذار این مسیرها را عوض کند، `check` خطا نشان می‌دهد. در آن صورت خروجی‌اش را برای Claude بفرستید.

## هزینه و سقف مصرف

- **مدل:** Claude Haiku 5.5، ارزان‌ترین و سریع‌ترین مدل، با «فکر کردن» خاموش. استخراج گزارش به فکر کردن نیاز ندارد.
- **هر گزارش:** تقریباً ۲ هزار توکن ورودی و ۲۰۰ توکن خروجی، یعنی حدود ۰٫۰۳ سنت.
- **ده نفر، ماهی ۳۰ روز، روزی دو پیام:** کمتر از ۲۰ سنت در ماه. حتی اگر سه‌چهار برابر هم بشود، زیر یک دلار است.
- **کارهایی که اصلاً Claude را صدا نمی‌زنند:**
  - دکمه‌ها، خلاصهٔ شب، برنامهٔ فردا و یادآوری‌ها
  - عدد خالی، مثلاً «۴۸» از سامی
  - «امروز نیستم»
  - پیام ظهر، که به‌طور پیش‌فرض با قالب ساخته می‌شود (`"noon_ai": false`)
- **پیام‌های پشت سر هم یکی می‌شوند:** پیام‌هایی که یک نفر تا ۴۰ ثانیه پشت هم می‌فرستد، با یک درخواست پردازش می‌شوند.
- **سقف ماهانه:** `"monthly_budget_usd": 5`.
  - در ۸۰٪ سقف، به مدیر خبر داده می‌شود.
  - بعد از سقف، ربات تا آخر ماه فقط با دکمه کار می‌کند.
  - مصرف این ماه در صفحهٔ «کاربران و Claude» دیده می‌شود.
- **تبدیل صوت** جداگانه حساب می‌شود و احتمالاً از خود Claude گران‌تر است. قیمتش را از سرویسی که انتخاب می‌کنید ببینید.

## صوت

**بدون هزینه (پیش‌فرض):** سرویس صوت را خالی بگذارید.
- در **بله** نیروها «تبدیل به متن» خود بله را روی صوتشان می‌زنند و متن را می‌فرستند.
- در **تلگرام** با میکروفون کیبورد گوشی حرف می‌زنند تا کیبورد تایپ کند.
- اگر ویس بفرستند، ربات همین را به آن‌ها می‌گوید.

**با سرویس تبدیل صوت (اختیاری):** اگر خواستید ربات خودش ویس را بفهمد:

هر سرویسی که API تبدیل صوت سازگار با OpenAI داشته باشد کار می‌کند:

```json
"stt_url": "https://api.openai.com/v1/audio/transcriptions", "stt_key": "sk-...", "stt_model": "whisper-1"
```

یا Groq، که ارزان‌تر و سریع‌تر است:

```json
"stt_url": "https://api.groq.com/openai/v1/audio/transcriptions", "stt_key": "gsk_...", "stt_model": "whisper-large-v3"
```

یا یک سرور Whisper محلی روی همان سرور، با حدود ۴ گیگ رم آزاد. اسم آدم‌ها و کارها به‌عنوان راهنما به Whisper داده می‌شود، و Claude اسم‌های اشتباه را با فهرست تیم تطبیق می‌دهد.

## به‌روزرسانی خودکار

از نسخهٔ ۰.۹، سرور هر ۵ دقیقه نسخهٔ تازه را از مخزن GitHub (`shahcheshme70-cando/rooznegar`) می‌گیرد و خودش نصب می‌کند.
اگر نسخهٔ تازه درست بالا نیاید، نسخهٔ قبلی خودش برمی‌گردد و به مدیر خبر داده می‌شود. بعد از هر به‌روزرسانی موفق هم فهرست تغییرها در تلگرام برای مدیر می‌آید.

راه‌اندازی یک‌باره: `sudo ./setup-autoupdate.sh` (یک توکن فقط‌خواندنی GitHub می‌خواهد).
دیدن وضعیت: `systemctl list-timers rooznegar-update` و `journalctl -u rooznegar-update -n 20`
نسخهٔ فعلی: `rooznegar version` یا `https://<دامنه>/healthz`

## نگه‌داری

- **داده:** همه‌چیز در `/var/lib/rooznegar/data.json` و فایل‌های رسیده در `/var/lib/rooznegar/files/` است. برای پشتیبان، از همین پوشه یک نسخه بگیرید.
- **لاگ:** `journalctl -u rooznegar -f`
- **به‌روزرسانی:** بستهٔ تازه را باز کنید و دوباره `sudo ./install.sh همان-دامنه` بزنید. تنظیمات و داده دست نمی‌خورند. بعد `sudo systemctl start rooznegar`.

## محدودیت‌های این نسخه

- اگر کانال فایل‌ها تنظیم نشود، فایل‌ها روی سرور ذخیره می‌شوند و فقط تا ۲۰ مگ جا می‌شوند.
- ربات فقط در گفتگوی خصوصی کار می‌کند، نه در گروه.
- اگر API بله از سرور جواب ندهد، `rooznegar check` خطا را نشان می‌دهد. در آن صورت آن نفر را روی تلگرام بگذارید.
